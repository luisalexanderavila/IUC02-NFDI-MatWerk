# NFDI-MatWerk Infrastructure Use Case IUC02 - Framework for Curation and Distribution of Reference Datasets

Welcome to the Git repository of the ["Infrastructure Use Case IUC02 - Framework for Curation and Distribution of Reference Datasets"](https://nfdi-matwerk.de/about/nfdi-matwerk-structure/use-cases/iuc02) of the consortium [NFDI-MatWerk](https://nfdi-matwerk.de/). Our demonstrator concept is explained ["here"](https://nfdi-matwerk.de/solutions/demonstrators/development-and-application-framework-for-distribution-of-reference-datasets).

In this repository you find all files and related information regarding our published and ongoing work.

### NFDI-MatWerk/IUC02 Definition for Reference Data of Materials

This definition was agreed within the IUC02. It is broadly formulated to cover experimental and simulation MSE data and is planned to be further developed in agreement with the MSE community.

Current version: [https://doi.org/10.5281/zenodo.11667674](https://doi.org/10.5281/zenodo.11667674).

### NFDI-MatWerk/IUC02 Data schema for creep data of Ni-based superalloys including a comprehensive documentation of test results and metadata

The basis for data structuring and reporting for the use case for creep data of Ni-based superalloys. It includes a community-agreed requirements profile for reference data. Please see [https://doi.org/10.5281/zenodo.11668375](https://doi.org/10.5281/zenodo.11668375) and the folder "Data Schema". Current version: v2.1

### BAM Reference Data: Creep of Single-Crystal Ni-Based Superalloy CMSX-6

The reference dataset can be found under [https://doi.org/10.5281/zenodo.13937987](https://doi.org/10.5281/zenodo.13937986). Current version: v2.1. The demonstrator works currently with v1.0.

### Data descriptor Article: Creep reference data of single-crystal Ni-based superalloy CMSX-6

The article that describes the reference dataset in a comprehensive manner. [https://doi.org/10.1016/j.dib.2025.112436](https://doi.org/10.1016/j.dib.2025.112436)

### Demonstrator App

Application that exemplary shows a data validation workflow considering RDF files and SHACL shapes based on the community-agreed requirements profile. [Visit it here](https://iuc-02-demonstrator.vercel.app). Currently with limited functionality. Further development is ongoing.

### AgentSem: Agent-based semantic data generator.

Agent-based semantic data generator. Try out and read more about the App on its Webpage: [AgentSem](https://agent-rdf-shacl-creator-0f2d13e6fb10.herokuapp.com/)

### Data transformation pipeline from ASCII to JSON

In the folder "Parsing" you will find documentation and scripts regarding the data transformation pipeline from ASCII to JSON. A data validation against the community-agreed requirements profile at the level of JSON files is included.

### Ontology Development - Knowledge Graph for Creep Reference Datasets

In the folder "Reference_Dataset_Ontology" you will find a previous (interrupted) work reagarding the Reference Data Ontoloty (RDO).

The current status of the developments related to the semantical representation of the published dataset and the integration into the ["The Materials Science and Engineering (MSE) Knowledge Graph"](https://nfdi.fiz-karlsruhe.de/matwerk/) are in the folder "Knowledge-Graph-for-Creep-Reference-Datasets".
